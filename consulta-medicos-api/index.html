Validação de entrada
UF precisa ser uma sigla brasileira, CRM só aceita dígitos (1 a 8) e é obrigatório informar CRM ou nome. Erros voltam como HTTP 400 com o motivo por campo.

            
Provedor plugável
PROVIDER=cfm consulta o endpoint público do portal do CFM com timeout configurável; PROVIDER=mock gera dados fictícios determinísticos para testes e demonstrações.

            
Normalização
Os campos crus do portal (NM_MEDICO, NU_CRM, SITUACAO…) viram um JSON estável: nome, CRM, UF, situação Regular/Irregular, especialidades e inscrição.

            
Cache e CORS
Respostas ficam em cache em memória por CACHE_TTL segundos e saem com cabeçalhos CORS, prontas para um front-end ou um robô RPA consumir.
