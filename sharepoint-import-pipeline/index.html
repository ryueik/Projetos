RPA · Cloud Flow · Microsoft Graph

Pipeline de importação para o SharePoint

Um fluxo agendado do Power Automate pega os arquivos que as rotinas desktop deixam numa pasta, transforma cada linha em item de lista e envia em lotes de 20 pelo $batch do Microsoft Graph. Throttling é tratado com Retry-After e backoff; o que falha de vez vai para um CSV de dead-letter, sem derrubar o resto da carga.

Gatilho de recorrência

O fluxo Cloud roda a cada 15 minutos e lista os .csv que o PAD deixou na pasta de importação da biblioteca.

Parse e montagem

Cada linha vira um POST /sites/{site}/lists/{lista}/items com o objeto fields; números são convertidos para float.

Lotes de 20 no $batch

O JSON batching do Graph aceita até 20 requisições por chamada: 1.000 itens viram 50 chamadas em vez de 1.000.

Retry com Retry-After

Respostas 429/503/504 aguardam o tempo pedido pelo servidor (ou backoff exponencial com jitter) e reenviam só os itens que falharam.

Try / Catch e dead-letter

Erros permanentes vão para um CSV de dead-letter; se o escopo inteiro falhar, o arquivo vai para Erro/ e um e-mail de alerta é enviado.
