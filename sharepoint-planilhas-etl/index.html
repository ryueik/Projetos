Planilhas prontas para o SharePoint

Como funciona

Do Excel bagunçado à lista

PAD vigia a pasta

O fluxo do Power Automate Desktop pega cada planilha nova da pasta de entrada e chama o etl.py com Run DOS command.

Cabeçalhos viram nomes internos

“Nº Patrimônio ” e “patrimonio” viram Title; “Valor (R$)” vira ValorAquisicao. Acento, caixa e espaço não importam.

Limpeza e validação

Datas para ISO 8601, números no padrão brasileiro para ponto decimal, status conferido com a coluna Choice, chave sem duplicatas.

Saída em duas partes

O CSV limpo vai para a biblioteca sincronizada; os rejeitados seguem por e-mail com o motivo de cada linha. Código de saída 2 avisa o PAD.
