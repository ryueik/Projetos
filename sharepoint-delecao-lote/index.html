Como funciona

Rápido, mas dentro da regra

Página de IDs

Busca só o id dos itens que casam com o filtro ($select=id&$top=999), seguindo o @odata.nextLink até o teto de 5.000.

DELETE em $batch

Agrupa 20 exclusões por chamada. Cada sub-requisição conta na cota, então o lote reduz a latência, não o consumo.

Token bucket

O cliente só envia quando tem fichas: a taxa fica em ~90% da cota e nunca dispara uma rajada maior que alguns segundos de consumo.

Retry-After é lei

Ao receber 429, todos os workers param pelo tempo pedido. Insistir durante o bloqueio só estende a punição, como mostra o modo “sem controle”.

Checkpoint

Após cada lote, os IDs pendentes vão para um JSON. Se a execução cair, a próxima continua de onde parou.
