Como funciona

Cinco passos, zero digitação manual

Abrir o navegador e o site

press("win"), digita o nome do navegador, enter e escreve a URL do sistema. pyautogui.PAUSE = 1 dá um respiro entre os comandos.

Fazer login

Posiciona o mouse, navega com tab entre e-mail e senha e confirma com enter.

Importar a base

pandas.read_csv("produtos.csv") carrega a planilha com código, marca, tipo, categoria, preço, custo e observação.

Cadastrar um produto

Clica no primeiro campo e, para cada coluna, write() + tab. Observações vazias (nan) são puladas; enter envia.

Repetir para toda a base

O for linha in tabela.index repete o cadastro e rola a página ao topo (scroll(10000)) antes do próximo item.

import pyautogui, time, pandas
pyautogui.PAUSE = 1

tabela = pandas.read_csv("produtos.csv")

for linha in tabela.index:
    pyautogui.click(x=856, y=286)   # campo "código"
    pyautogui.write(tabela.loc[linha, "codigo"])
    pyautogui.press("tab")
    pyautogui.write(tabela.loc[linha, "marca"])
    pyautogui.press("tab")
    # ... tipo, categoria, custo, preco_unitario
    obs = str(tabela.loc[linha, "obs"])
    if obs != "nan":
        pyautogui.write(obs)
    pyautogui.press("tab")
    pyautogui.press("enter")         # enviar
    pyautogui.scroll(10000)          # volta ao topo
